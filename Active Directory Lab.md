# Active Directory User Management Lab

### Objective
Simulate common Tier 1 help desk tasks using Active Directory.

### Tasks Performed

- Create, modify, and delete user accounts in Active directory
- Reset passwords and unlock user accounts when users are locked out
- Manage user attributes like email addresses, group memberships, and contact detail
- Enable or Disable user accounts as needed
  
- Create and manage security and distribution groups
- Add or remove users from groups to control access to resources like files, printers, and applications
- Simulate assigning permissions to files or folders on a network share

- Joined virtual machines to a domain in a test lab
- Created Documentation

### Tools Used
- Windows Server (Lab Environment)
- Active Directory Users and Computers

### Outcome
Successfully resolved common identity-related issues that are frequently escalated to help desk teams.


### How to create a user account in active directory?
1. Open Active Directory Users and Computers (ADUC).
2. Navigate to the desired Organizational Unit (OU) or container where you want to create the user.
3. Right-click the OU or container, select New, then click User.
4. Enter the user’s First name, Last name, and User logon name (username), then click Next.
5. Set the user’s password, confirm it, and choose the appropriate password options (e.g., user must change password at next logon), then click Next.
6. Review the information and click Finish.
